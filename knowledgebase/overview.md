## What is MockNetPackKit

`MockNetPackKit` is the **iOS Debug SDK** of MockNetPack: an in-app HTTP capture and remote-mock client embedded in the business app's **Debug build only**. It captures every HTTP request/response made by the app process, uploads them to the central mock server, and — while a capture session is active — returns server-configured mock responses *locally in the app* for matching requests. No system proxy, no certificate, no business-network-layer changes: interception is installed by swizzling `URLSessionConfiguration` and registering a global `URLProtocol`.

The SDK is a **Swift Package** (`Package.swift`) that also ships as a **CocoaPods pod** (`MockNetPackKit.podspec`, version `0.2.0-m9`).

## Role in the product

| Product role | What the SDK does |
|---|---|
| Traffic source | Captures in-app HTTP traffic and uploads it (batched) to the server |
| Remote mock client | Pulls the device's active mock rules from the server, matches `Method + URL path` locally, and serves canned responses in-process |
| Fail-open | If the server is unreachable or rule sync fails, business requests continue untouched |
| Debug-only | SDK never decides Debug vs Release — the integrating app's build config excludes it from Release (hard requirement, M5 verified) |

## Key concepts

| Concept | Meaning (SDK side) |
|---|---|
| `did` | Device identifier generated by the SDK (UUID) or supplied by the host app; persisted per app (`DIDStore`); the full device identity is `(App, did)` |
| Capture session | A server-side, Web-activated capture period. The SDK learns its state from the heartbeat response's `session` field — non-null ⇒ capturing, null ⇒ idle |
| `idle` / `capturing` | `SessionState` derived from heartbeat. Capture/mock only runs while `capturing` |
| Connection state | `connecting` / `connected` / `offline`; `offline` = heartbeat failing with backoff, or device not registered (404); `unconfigured` (M9.2) = no saved server address yet, waiting for scan |
| Server address (M9.2) | No hard-coded server: `connectByScan` saves the scanned server URL (`ServerAddressStore`), `start(did:)` reads it for direct connect — device re-registration after restart needs no scan (A2) |
| Pairing token (M9.2) | 10-min QR token issued by the Web (logged-in user); register carries `pairingToken` ⇒ auto-register device under that user (D1); `(app, did)` idempotent — existing device is reused, not recreated (D7) |
| Fail-open A (rules) | Rule pull failure: no snapshot yet ⇒ don't mock; stale snapshot exists ⇒ keep using it |
| Fail-open B (capture) | `canInit` returns false when not capturing; SDK own requests are never intercepted |
| Skip header | `X-MockNetPack-Skip` marks SDK-internal requests (register/heartbeat/upload) so the interceptor lets them pass |

## Integration surface (the only public API)

```swift
MockNetPackKit.start(server: URL, appID: String? = nil, did: String? = nil,
                     appVersion: String? = nil, logHandler: ((String) -> Void)? = nil)
MockNetPackKit.stop()
MockNetPackKit.registerBinaryCodec(for contentTypeKey: String,
                                   compression: BinaryCompression,
                                   responseEncrypt: @Sendable (Data) -> Data?,
                                   responseDecrypt: @Sendable (Data) -> Data?,
                                   requestEncrypt: (@Sendable (Data) -> Data?)? = nil,
                                   requestDecrypt: (@Sendable (Data) -> Data?)? = nil)

// Read-only state & callbacks
MockNetPackKit.did / isRunning / connectionState / sessionState
MockNetPackKit.onSessionStateChange / onConnectionStateChange
```

The host app typically: calls `start(server:)` at launch (Debug only), optionally passes its own `did`, and registers a binary codec when the app uses a private binary protocol (e.g. xcp AES+gzip). Everything else is internal.

## Key numbers (facts, not config)

| Item | Value | Where |
|---|---|---|
| SDK version | `0.2.0-m9` | `MockNetPackKit.version` |
| Heartbeat interval | Server-driven: **3s capturing / 5s idle** (dynamic since M8.2/M8.3), clamped 5…300s | `ConnectionController.heartbeatInterval()` |
| Heartbeat backoff | Exponential 1s → max 30s | `advanceBackoff()` |
| Traffic batch | 200 entries / 8 MB / 2s flush; contract max 500 per upload | `TrafficCaptureController` |
| Body truncation | 1 MB per body (fixed, contract v0.2.0) | `MockNetPackURLProtocol.bodyLimit` |
| Upload failure | Batch dropped, no retry, no local cache (F7.6) | `TrafficCaptureController.flush()` |
| Registration semantics | M7.2.3+: SDK **does not auto-register**; 404 from register/heartbeat ⇒ silent stop (no retry) until app restart | `ConnectionController.performCycle()` |
| Mock match | `Method (case-insensitive) + URL path`, host ignored, query/body ignored | `MockRuleController.match()` |
